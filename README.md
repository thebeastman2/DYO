## Methodology

DYO follows a professional statistical arbitrage workflow:

1. Select two financial assets.
2. Download and preprocess historical market data.
3. Estimate the optimal hedge ratio.
4. Construct the price spread.
5. Evaluate statistical validity through multiple hypothesis tests.
6. Measure current deviation using standardized Z-scores.
7. Generate trading signals.
8. Backtest the strategy across historical data.
9. Evaluate risk-adjusted performance.
10. Simulate future outcomes using Monte Carlo methods.
